Counting guide
Word-compatible counts
The word and character counts approximate Microsoft Word’s desktop Word Count dialog for plain text. “Peer-to-peer” counts as one word. The character counts use code points, omit tabs and line breaks, and differ in whether they include spaces.
Unicode word count
The default word boundaries in Unicode 18.0 (Standard Annex #29) divide the text into segments. Each segment containing a letter or number counts as one word. Each Han ideograph normally forms its own segment.
Linguistic word count
Language-aware segmentation recognizes words across scripts, including Chinese words with multiple characters. Numbers count as word segments. “Peer-to-peer” has three word segments. Results can vary with the browser’s language data.
Unicode characters
Under Unicode 18.0, one extended grapheme cluster counts as one character, including a letter with a combining accent or a family emoji. Spaces and explicit line breaks count. A carriage return followed by a line feed counts once.
Han characters
Counts unified and assigned compatibility Han ideographs, plus 〇. This includes Chinese characters used in Japanese and Korean text.
Sentences, paragraphs, and text lines
Each sentence segment that contains a letter or number counts once. A paragraph is a nonblank segment between paragraph breaks, including ordinary newline characters. Text lines include blank lines and a final empty line after a line break. Screen wrapping leaves the line count unchanged.
